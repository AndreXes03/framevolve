# Framevolve

Make motion. Keep control.

- [Live demo and downloads](https://framevolve.andreasalvo.chatgpt.site/)
- [Browser Studio](https://framevolve.andreasalvo.chatgpt.site/studio/)
- [Framevolve GitHub Pages link](https://andrexes03.github.io/framevolve/)
- [Product source and development](https://github.com/AndreXes03/motion-lab)

This repository provides the Framevolve public links. GitHub Pages redirects to the current live demo, so the link follows future demo updates without maintaining a second copy of the application.

Product development stays in the existing Motion Lab repository to preserve active branches, pull requests and local installations. The previous Motion Lab links remain valid.

Local Studio and agent integration are currently macOS beta. Blender Cycles requires a local installation and a supported scene.
